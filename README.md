# 💳 Financial Fraud Detection & Risk Analysis Dashboard

## 📌 Project Overview

This project is an end-to-end Financial Fraud Detection and Risk Analysis solution built using Python, SQL, Machine Learning, and Power BI.

The project analyzes transaction behavior, identifies high-risk fraud patterns, and provides actionable business insights through an interactive dashboard.

The main objective of this project is to help financial organizations detect fraudulent transactions, reduce financial losses, and monitor suspicious customer activities.

---

# 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SQL
* Scikit-learn
* Power BI

---

# 📊 Project Workflow

## 1️⃣ Data Cleaning & Preprocessing

* Handled missing values
* Removed duplicates
* Processed outliers
* Cleaned transaction data using Pandas

## 2️⃣ Exploratory Data Analysis (EDA)

* Fraud distribution analysis
* Transaction amount analysis
* Fraud trend visualization
* Product risk analysis
* Correlation heatmap generation

## 3️⃣ Feature Engineering

Created advanced fraud detection features such as:

* Transaction frequency
* Average transaction amount
* Time-based behavior analysis
* Risk indicators

## 4️⃣ Machine Learning Models

Built fraud detection models using:

* Logistic Regression
* Random Forest

### Model Performance

* Accuracy: 97%
* ROC-AUC: 0.96
* Precision: 90%
* Recall: 80%

## 5️⃣ SQL Fraud Analysis

Performed SQL-based analysis for:

* High-risk customer cards
* Fraud percentage trends
* Email domain fraud analysis
* Fraud transaction patterns

## 6️⃣ Power BI Dashboard

Designed an executive-level dashboard featuring:

* Fraud KPIs
* Fraud trend analysis
* Risk analysis
* Customer fraud insights
* Key business insights
* Interactive filters and slicers

# 📈 Key Insights

* Fraud rate detected: 2.56%
* Total fraud amount identified: $342K+
* Product Type W showed highest fraud volume
* Fraud activity increased during night and early morning hours
* High-risk customer cards showed fraud rates between 87–100%
